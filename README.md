# V4 PILOTE — UL Basse Loire
Inclut : notes de frais avec OCR photo, justificatifs, mail .eml avec pièces, mail .eml pour scan, banques, journal, rapprochement CSV, clôture et publication préparatoires.

**Limites :** prototype local, sans comptes utilisateurs réels, synchronisation ou envoi automatique. Le fichier .eml doit être ouvert dans une messagerie compatible et envoyé manuellement. Gmail Android peut ne pas prendre en charge .eml. Les états de clôture et publication ne sont pas réglementairement complets : ne pas publier tels quels. Ne pas saisir de données confidentielles réelles.

**Installation :** décompresser le ZIP, remplacer les 7 fichiers du dépôt GitHub Pages, attendre la publication, ouvrir l'URL du site dans Chrome Android, menu ⋮ → Installer l'application / Ajouter à l'écran d'accueil. Sauvegarder les données depuis Plus avant mise à jour. Ne pas effacer les données du site.
